# Course 8: Data Visualization with Python

This folder contains my final assignment work for **Course 8** of the IBM Data Science Professional Certificate: *Data Visualization with Python*.

---

## Course Overview

Course 8 is the second intermediate module in the certificate program, focused on teaching how to present and communicate data insights effectively using visual tools and libraries.

Key topics covered:
- Creating **plots and charts**: histograms, bar plots, pie charts, scatter plots, area charts, word clouds
- Using visualization libraries such as **Matplotlib, Seaborn, Folium, Plotly, and Dash** 
- Designing simple **interactive dashboards**, including geospatial and airline performance visual dashboards

---

## What I Learned

- How to design effective visual representations of data  
- Using **Seaborn** and **Matplotlib** for static visualizations and exploratory data visualization  
- Leveraging **Plotly** and **Dash** to create interactive charts and dashboards  
- Displaying geospatial insights using **Folium** or location-based plotting tools  
- Communicating patterns, trends, and stories through clean and intuitive visuals

---

## Skills Applied

- Matplotlib & Seaborn for basic and advanced charting  
- Plotly for interactive graphs  
- Dash for simple dashboard construction  
- Folium or Map-based tools for geospatial visualizations  
- Interpreting visual output to highlight actionable insights
