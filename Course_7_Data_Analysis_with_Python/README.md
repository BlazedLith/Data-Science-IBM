# Course 7: Data Analysis with Python

This repository contains my work for Course 7 of the IBM Data Science Specialization: **Data Analysis with Python**. The course focuses on using Python libraries to analyze data, build predictive models, and extract insights from datasets.

## Repository Structure

### Module-by-Module Labs
Contains 5 Jupyter notebooks covering the data analysis pipeline using a laptop pricing dataset:
- **Data-Importing.ipynb**: Dataset loading and initial exploration
- **Data-Wrangling.ipynb**: Data cleaning, preprocessing, and transformation
- **EDA.ipynb**: Exploratory data analysis with visualizations and statistical analysis
- **Model-Development.ipynb**: Building and comparing different regression models
- **Model-Evaluation.ipynb**: Model validation, cross-validation, and hyperparameter tuning

### Final Project
- **House-Price-Prediction.ipynb**: Complete end-to-end analysis of King County house sales data to predict house prices

## What I Learned

### Technical Skills
- **Data Import & Manipulation**: Using pandas to load, clean, and transform datasets
- **Data Visualization**: Creating meaningful plots with matplotlib and seaborn
- **Statistical Analysis**: Descriptive statistics, correlation analysis, and hypothesis testing
- **Machine Learning**: Linear regression, polynomial regression, Ridge regression
- **Model Evaluation**: Cross-validation, grid search, overfitting detection, and performance metrics (MSE, R²)

### Libraries Used
- **pandas**: Data manipulation and analysis
- **numpy**: Numerical computing
- **matplotlib & seaborn**: Data visualization
- **scikit-learn**: Machine learning algorithms and model evaluation
- **scipy**: Statistical functions

### Key Concepts Mastered
- Data cleaning and preprocessing techniques
- Feature engineering and selection
- Model building and evaluation strategies
- Cross-validation and hyperparameter tuning
- Identifying and preventing overfitting
- Pipeline creation for streamlined workflows
